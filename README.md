# synent-task5# Sales Data Analysis using Superstore Dataset

## 📌 Problem Statement

Businesses generate large volumes of sales data every day. Analyzing this data helps identify revenue trends, top-performing products, profitable regions, and opportunities for business growth.

The objective of this project is to analyze Superstore sales data and derive meaningful business insights using Python and data visualization techniques.

---

## 📂 Dataset Details

**Dataset Name:** Superstore Sales Dataset

**Rows:** 1000+ records (based on uploaded dataset)

**Main Columns Used:**

* `order_date`
* `region`
* `category`
* `sub_category`
* `product_name`
* `sales`
* `profit`

The dataset contains transactional sales records across different products, categories, and regions.

---

## 🛠 Tools & Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab

---

## 🔍 Project Objectives

The following business questions were analyzed:

1. What are the monthly revenue trends?
2. Which products/categories generate the highest sales?
3. Which regions generate the highest profit?
4. How can business performance be improved?

---

## 📊 Approach

### 1. Data Cleaning

* Loaded dataset using Pandas
* Checked missing values
* Removed duplicate records
* Converted `order_date` to datetime format
* Standardized column names

### 2. Exploratory Data Analysis

Performed analysis on:

* Monthly Revenue Trends
* Top Selling Products
* Region-wise Profit Analysis
* Category-wise Sales Performance

### 3. Data Visualization

Used line charts, bar charts, and horizontal bar charts to present insights clearly.

---

## 📈 Key Results & Insights

### Monthly Revenue Trends

* Sales remained mostly stable across months.
* Highest revenue observed in **March 2024**.
* Strong peaks also seen in **April 2023** and **July 2023**.
* Lowest revenue observed in **May 2024**.

### Top-Selling Products

Top revenue-generating categories:

1. Storage
2. Chairs
3. Bookcases
4. Binders

### Profit by Region

| Region  | Profit   |
| ------- | -------- |
| West    | 15094.10 |
| East    | 13518.04 |
| South   | 12416.98 |
| Central | 11365.16 |

### Final Business Insights

* West region is the most profitable market.
* Furniture and office-related products perform strongly.
* Central region requires business improvement strategies.
* Revenue drop in May 2024 should be investigated.
* Focus on top-performing products for higher returns.

---

## 📌 Recommendations

1. Expand successful strategies from West region to other regions.
2. Improve marketing in Central region.
3. Maintain inventory for high-demand categories.
4. Use monthly trends for demand forecasting.
5. Optimize low-performing product categories.
